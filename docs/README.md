# Документация

Спеки v1 (контент, экраны, решения, план) живут в репозитории игры: `Kloviko-Studio/PourAndSlay`, папка `docs/`. Здесь — решения по HTML-прототипу.

## Связь с доками игры

- **Доки игры — источник правды.** Прежде чем менять в концепте правила, числа, экраны или арт, сверяйся с `pour-and-slay/docs/` (`content/`, `screens/`, `art/`, `decisions/`, `CONTEXT.md`). Если концепт должен разойтись с доками — не меняй молча, а предложи переделать доки (или ADR).
- **Доки всегда актуальны концепту.** Каждая правка концепта в той же работе переносится в доки игры: числа, id, поведение экранов, порядок анимаций, скриншоты (`node tools/shoot-screens.mjs`), уроки для приложения на React Native (`docs/lessons.md`).
- **Исключение** — то, что решено в концепте не делать, а делать сразу в приложении (например, живой фон главного экрана). В доках это помечено явно («в прототипе нет, делается в приложении»); такие места — не расхождение и правки концепта не требуют.

## Прототип

`index.html` в корне — концепт v2 всей v1 (он же страница GitHub Pages). Открывается двойным кликом, сервер не нужен. Устройство — [v2/ARCHITECTURE.md](v2/ARCHITECTURE.md), трудности и как их решили — [v2/LESSONS.md](v2/LESSONS.md). Бот и тесты ядра — `node bot/sim.js`, `node bot/test-*.js`; игру через интерфейс с замером кадров — `node tools/playtest.mjs` (описание ключей в шапке файла). Первый прототип сохранён в `legacy/v1.html`.
